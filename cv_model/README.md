# Модуль компьютерного зрения

Модуль предназначен для обучения и тестирования модели детекции человека на изображениях, полученных из виртуальной сцены UNIGINE.

В качестве исходной модели используется YOLO11n из библиотеки Ultralytics. Модель была дополнительно обучена на собственном наборе изображений, сформированном с помощью виртуальных камер проекта.

## Выполненные задачи

- сбор изображений из виртуальной сцены UNIGINE;
- разметка людей на изображениях в формате YOLO;
- разделение данных на обучающую, валидационную и тестовую выборки;
- оценка исходной модели YOLO11n;
- дообучение модели на собственном датасете;
- оценка дообученной модели на независимой тестовой выборке;
- сохранение весов, графиков обучения и примеров детекции.

## Датасет

Датасет сформирован из изображений, полученных с двух виртуальных камер сцены UNIGINE. Всего было подготовлено 301 изображение, содержащее 218 размеченных экземпляров класса `person`. Данные были разделены на обучающую, валидационную и тестовую выборки.

| Выборка | Изображений | Людей |
| :--- | ---: | ---: |
| Обучающая | 141 | 91 |
| Валидационная | 40 | 30 |
| Тестовая | 120 | 97 |
| **Всего** | **301** | **218** |

В датасет также включены 83 фоновых изображения без людей. Они используются для того, чтобы модель училась отличать человека от других объектов виртуальной сцены.

Разметка выполнена в формате YOLO. В проекте используется один класс — `person` с идентификатором `0`.


## Обучение модели

Дообучение выполнено на основе модели YOLO11n.

Основные параметры обучения:

| Параметр | Значение |
|---|---:|
| Размер изображения | 640 × 640 |
| Количество эпох | 50 |
| Размер пакета | 8 |
| Early stopping patience | 10 |
| Seed | 42 |
| Класс | `person` |

Эксперименты проводились на компьютере Apple M3 с использованием ускорения MPS.

## Результаты

Исходная и дообученная модели были проверены на тестовой выборке, содержащей 120 изображений и 97 экземпляров класса `person`.

| Модель | Precision | Recall | mAP50 | mAP50–95 |
|---|---:|---:|---:|---:|
| Исходная YOLO11n | 0,980 | 0,498 | 0,829 | 0,609 |
| Дообученная YOLO11n | 0,960 | 0,988 | 0,975 | 0,564 |

После дообучения Recall увеличился с 0,498 до 0,988, а значение mAP50 — с 0,829 до 0,975. Таким образом, модель стала находить значительно больше людей на изображениях из виртуальной сцены.

При этом значение mAP50–95 снизилось с 0,609 до 0,564. Это показывает, что на строгих порогах IoU точность локализации ограничивающих рамок требует дальнейшего улучшения.
